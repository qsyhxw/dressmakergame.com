Dressmaker System Requirements

The complete Dressmaker release is scheduled for September 21, 2026 globally. Steam and the official press kit confirm Windows and macOS for the full game; the separate itch.io Prototype 0.5.5 also has a Linux file. This page keeps those platform claims separate.

Quick Answer

For Windows, Steam lists Windows 10+, an Intel Core i5 or AMD Ryzen, 8 GB RAM, Intel UHD 630 or better, DirectX 11, and 1 GB storage. macOS lists Apple M1, 8 GB RAM, and 1 GB storage. A full-release Linux build and Steam Deck Verified status are not confirmed by the official platform list.

Can My PC Run Dressmaker?

  1. Windows players: check that you are on Windows 10 or later, have 8 GB RAM, DirectX 11 support, and graphics at least around Intel UHD 630 or better.
  2. Mac players: the Steam page lists Apple M1 as the minimum. The itch.io prototype has an OSX/macOS file, but the page notes the app is not notarized.
  3. Linux players: Prototype 0.5.5 has a Linux zip, but its availability does not confirm a Linux build of the complete Steam release.
  4. Storage planning: Steam lists 1 GB available space for the full Windows/macOS release; prototype zip files are smaller, but leave extra room for extracted files and saves.

Steam Deck Notes

No separate Steam Deck Verified status is confirmed, and the current official platform list for the complete game is Windows and macOS. The itch.io prototype's Linux zip is not proof of full-release Linux or Steam Deck support.

  • Do not assume Verified status until Steam displays it.
  • If you are planning for Deck play, check the live Steam compatibility panel before buying.
  • The current itch.io prototype is a desktop download; there is no official Android or iOS version listed.

FAQ

How much RAM does Dressmaker need?

The Steam page lists 8 GB RAM for Windows and macOS. No full-release Linux requirement is confirmed on this page.

How much storage does Dressmaker need?

Steam lists 1 GB available space for Windows and macOS. The separate itch.io prototype zip files are 115-128 MB before extraction.

Can I play Dressmaker on an old Intel laptop?

For the Steam version, compare your laptop with Intel UHD 630 or better graphics, an i5/Ryzen class CPU, and 8 GB RAM. If your device is below those specs, wait for more launch feedback before buying.

Is the Mac version notarized?

The current itch.io page says the Mac prototype is not notarized, so macOS may show a security warning. Steam requirements for the full version list Apple M1, 8 GB RAM, and 1 GB storage.
